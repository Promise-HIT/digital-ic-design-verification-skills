# Agent 编写 RTL 的检查方法

**改动前**。从实际 filelist、语言开关和顶层实例找到模块的工作配置。记录这次改动会影响的接口事件、可见延迟和复位行为。加入流水级、改变满时能否同时入队、改成异步复位，都可能改变调用方的契约。用相邻实例或规格核对，再动端口与状态。

| 下笔处 | 应在代码中能看见什么 | 如何发现写错 |
| --- | --- | --- |
| 组合译码与状态 | 输出在每条路径都有定义。SV 用 `always_comb` 表达组合意图，寄存状态在一个时序过程用 NBA 更新。旧 Verilog 按工程模式使用 `always @*`。通配译码列明哪些位允许忽略。 | 给重叠命中、无命中和非法控制值各走一遍。检查综合器推断的 latch、优先链与预期电路。普通 `case` 可显式匹配四态值，`casex` 会把未知控制位当通配。 |
| FIFO 指针、RAM 写使能和计数 | 从规格推导本拍实际接受的 push、pop。写指针与 RAM 写入共用 push，读指针用 pop，占用量在仅 push 时加一、仅 pop 时减一。 | 对空、部分占用、满分别列出双请求结果。深度 1 单独检查位宽，非二次幂深度检查最后合法地址后的回绕。读数据在接受拍或之后哪一拍有效由接口决定。 |
| 复位、CDC 和时钟使能 | 每个状态写明所属时钟、启动条件和复位释放方式。单比特慢变电平可按 MTBF 与库选同步链。短脉冲需要给出可捕获宽度或事件传递机制，多位快照需握手保持或异步 FIFO。 | 分别改变时钟相位、事件间隔和单域复位顺序。检查首级扇出、同步后重汇合、丢事件和重复事件。用 CDC/RDC 报告及实现约束检查结构，RTL 仿真观察功能。 |
| 算术与存储推断 | 写出每个中间量的位宽、符号和缩位点。拼接、截位、无尺寸字面量与混合符号会改变表达式。RAM 的同址读写、读延迟和是否清阵列由目标宏与可见行为决定。 | 用最大正值、最小负值、进位及同址读写检查。目标是 SRAM/BRAM 时查综合后的实际资源和端口配置。 |
| 低功耗边界 | 根据工程 UPF 的电源域和电源状态表确定 isolation 方向、钳位值、retention 和恢复顺序。时钟门控使用项目认可的 ICG 或 FPGA 时钟使能。 | 以一次带未完成请求的关电和唤醒为例，检查何时停止接受、何时隔离、何时重新宣告 valid。电源感知仿真与时序检查各记录自己的观察结果。 |

**课程 FIFO 的区分用例**。假设空时允许写入、拒绝读取，且没有空队列直通。在复位退出的第一个有效边沿同时请求读写 A。此时应留下一个 A，第二拍只读应取出 A。若计数只有在“写请求且无读请求”时才加一，它会继续报告空，而 RAM 已写入。这一结论依赖上述接受策略。具有直通语义的 FIFO 需要另外推导。

**交付**。附上使用的配置和边界激励、预期与实测，以及首次偏离的采样拍。修复接口错误时沿用同一输入在改动前后复跑。模块已有等价的构建或检查入口时，直接复用。

依据包括 IEEE 1800-2023 第 9、10、11、12 章，IEEE 1364-2005，《华为_Verilog HDL电路设计指导书》物理第 16 页，课程同步 FIFO 源码及《CDC相关知识点》。电源意图术语见 IEEE 1801-2018。教材中的命名和复位写法应与目标工程约定核对。

# 先画出电路，再写 HDL

以下页码为所引版本 PDF 的物理页。先读用户规格，写明时钟、复位、输入何时采样、输出在哪一拍有效。将规格中仍未定义的行为列为设计问题。下列练习里的时序只适用于练习本身。

## 写模块与命名

依据《数字 IC 工作学习资料整理》PDF 第 33–45 页。先看相邻模块怎样命名时钟、复位和低有效信号。新模块沿用同一套约定，文件名对应模块名，跨层级的同一信号保持可辨认。常数和参数用有意义的名称。端口逐行声明，明确方向和范围；每条语句单独一行，复杂表达式用括号表达运算次序。注释写清端口行为、编译条件和综合例外。整理已有代码时按改动范围执行。

## 从状态表生成组合和时序逻辑

依据《Verilog HDL 电路设计指导书》PDF 第 16 页关于输出时序和分支互斥的讨论，以及《数字 IC 工作学习资料整理》编码风格章。为每个当前状态列出输入条件、次态、输出和优先级。Moore 输出按当前状态译码；Mealy 输出同时依赖输入。两类状态机均须按输入条件决定次态。对可能重叠的条件先决定优先级，再选 if/else 或 case。组合分支覆盖每条输出路径，时钟沿更新状态。

下面是本项目推导的一个完整示例。同步低有效复位；采样到 req 后下一周期显示 busy，一旦采样到 done 就结束。用 Verilog-2001 编写：

```verilog
module busy_ctrl (
    input  wire clk,
    input  wire rst_n,
    input  wire req,
    input  wire done,
    output wire busy
);
    localparam IDLE = 1'b0, ACTIVE = 1'b1;
    reg state_q, state_d;

    always @* begin
        state_d = state_q;
        case (state_q)
            IDLE:    if (req)  state_d = ACTIVE;
            ACTIVE:  if (done) state_d = IDLE;
            default: state_d = IDLE;
        endcase
    end

    always @(posedge clk) begin
        if (!rst_n)
            state_q <= IDLE;
        else
            state_q <= state_d;
    end

    assign busy = (state_q == ACTIVE);
endmodule
```

将此模块用于 SV 工程时，按同一状态表把组合块写作 always_comb、寄存块写作 always_ff，状态可用显式位宽 enum logic。核对两版在复位、IDLE 收 req、ACTIVE 收 done 时的逐拍序列。端口与中间表达式的位宽、符号和截断位置可逐项对照第 45 页的操作数位宽要求；例如 W 位无符号数求和需要保留进位时，将两个输入各补一个前导零，结果接 W+1 位。

**交付**包括接口时序、代码、一个能区分两种实现的输入序列及观察结果。对于上例，在时钟沿之间切换 req，观察 busy 是否仅随状态更新；同时置位 req/done，分别核对当前状态为 IDLE 和 ACTIVE 的结果。
