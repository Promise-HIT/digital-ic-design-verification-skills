# 按首次可观察差异定位

| 症状 | 最小分辨实验 | 需保留的证据 |
| --- | --- | --- |
| FIFO 写了一个字却一直为空 | 在约定空不直通的配置下，从空态同时请求读写，再单独读；并排记录边沿前占用、两个接受事件、边沿后指针与计数。 | 首个接受事件与首次错误状态。若接口允许直通，按其输出时序重算预期。 |
| APB 一次访问出现多个写脉冲 | 对具有提交脉冲的从设备拉长 ACCESS，在同一笔访问内数实现规定的提交事件；随后背靠背向同一地址写两个不同值。 | setup、等待拍、完成拍，以及对外可见副作用。普通存储单元写入相同值两次，最终读回相等不能证明重复计数。 |
| 仿真通过，scoreboard 比较为零 | 依次找 test 启动、driver 接受、输入及输出 monitor 采样、期望入列和比较。对一条已比较的数据注错。 | 首个消失的事件、相应时钟和 reset、注错后的错误位置及正常结束条件。 |
| 负 slack 只在某配置出现 | 比较同一层次的时钟定义、生成时钟、例外、库角及寄生参数。分别看 max/setup 与 min/hold 的起止边沿及不确定度。 | 实际约束覆盖、被分析路径、单位和 analysis view。添加 false path 前需要协议或时钟关系依据。 |
| “Verdi”手册与仿真波形内容不符 | 看文档封面、产品名和对象类型。课程目录的 VERDI 2.2 User Manual 出现地理数据与地图绘图，不能作为 Synopsys Verdi 的波形命令依据。 | 回到项目 FSDB、调试构建目标和实际安装版本；商业工具选项由对应产品手册核对。 |

定位后用同一配置复跑最小触发条件。报告一条因果链：合法激励、首个不符契约的采样、可见影响、重现入口。静态推演与工具实测分别标明。
