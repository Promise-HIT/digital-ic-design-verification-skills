# 模块设计记录（按本次变更裁剪）

此模板只组织事实；未给出的规格不得凭模板猜测。

|项目|需记录的决策|
|---|---|
|来源|需求文档/接口版本、仓库约定、现有实现事实、显式假设|
|接口|信号方向、位宽/符号、时钟域、有效窗口、允许组合路径|
|事务|接受事件、输出事件、延迟、吞吐、顺序、最大 outstanding|
|阻塞|stall 保持字段、buffer 容量、长期背压、停钟行为|
|状态|每个寄存器的唯一更新块、enable、并发更新优先级|
|复位/取消|断言/释放、启动条件、flush、未完成事务去向|
|存储|深度、读延迟、读写同地址语义、宏/推断目标|
|边界|合法参数、深度 1/2/非 2 次幂、位宽 1、溢出/回绕|
|检查|需求 → test/property → 独立 checker → coverage → 证据|
|工具|top/filelist/defines、工具版本、实际命令和日志|

只对会影响接口/正确性且无法从工程确认的缺失信息提问；可撤销的局部实现选择先注明并继续。完成后报告实际结果与未验证项。
