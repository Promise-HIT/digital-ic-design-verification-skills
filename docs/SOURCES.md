# 来源与公开整理说明

本仓库由用户提供的数字 IC Skill 增强包整理而来。公开整理保留了三个 Skill、工程参考、模板和四个 Python 工具，补充仓库说明、安装器、自动校验与工具回归。

## 保留的来源信息

- RTL Skill 的 `source-catalog.json` 保留原包记录的文件名、来源 ID、SHA-256 和页数，删除个人电脑路径与重复路径别名。
- `book-source-notes.md` 保留原包的来源定位与工程取舍。这些是原包记录，本次没有重新取得或逐页审阅原书；页码可能随版本变化。
- 验证 Skill 的 `official-source-lock.json` 保留原包记录的 Accellera URL、取得日期、大小与哈希，并注明继承来源；本次未重新下载这些归档，不能声称已重新校验。

这些清单用于出处定位。公开使用者不需要拥有原作者的本地资料目录；需要查原图、公式或代码时，应自行使用合法取得的对应版本。

UVM 版本与工具命令以使用者实际工程为准。官方文档与版本实现优先于历史教材；遇到争议应核对对应原始来源，不把本仓库当成 IEEE 标准或厂商手册的替代品。
